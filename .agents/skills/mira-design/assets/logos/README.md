The Mira mark is a 5 by 5 pixel M on a rounded tile. Use `mira-mark-dark.svg` (white pixels on a black tile) on dark surfaces and `mira-mark-light.svg` (black pixels on a white tile with a hairline edge) on light surfaces. Each file carries fixed inks, so pick the file that matches the surface. Show the mark at 24px or larger and leave one pixel unit of clear space around the tile.
