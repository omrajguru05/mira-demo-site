Chip is a rounded pill for commands, attributes and short tags.

**You provide:** a `label`, and `mono` set to false for plain text labels.

- Set code and commands in mono (the default): `mira build`, `mira-morph`.
- Use plain text with `mono` false for status words such as Closed beta.
- Chips use `radius-pill`, a `line` border and a `surface-2` fill. Keep them to one line.
- Group chips with `space-2` gaps. In a box cell, place them under the body copy.
