CursorTag is a pointer with a colored name label, used to show collaborators and to annotate layouts.

**You provide:** a `name` and an optional `tone`. Position it with absolute or grid placement in your layout.

- Give each person one tone and keep it across the page.
- Use `cobalt` for white text. Use `ember`, `sun`, `lagoon` and `rose` for dark `on-warm` text.
- Round tags into pills with `radius-pill`, like every other label that can be named.
- Place tags beside the element they describe and let the pointer touch its corner.
