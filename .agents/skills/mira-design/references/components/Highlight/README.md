Highlight puts one key word on a colored block with four square selection handles, like a layer picked in a design tool.

**You provide:** the `text` and an optional `tone`. Place it inline inside a display headline.

- Use one highlight per headline, on the last word or phrase.
- Choose `sun` by default. Use `ember`, `lime` or `haze` for variety, and `cobalt` for a cool accent.
- Text on `sun`, `ember`, `lime` and `haze` uses `on-warm`. Text on `cobalt` uses `on-cool`. The component applies the right pair.
- Size the highlight with the headline. The handles stay 9px and sit 5px outside each corner.
