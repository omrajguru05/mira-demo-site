PixelIcon draws an interface icon from the pixel module of the logo: a glyph lit in one hue over a dim 12 by 12 grid of the same pixels.

**You provide:** the `name`, a `tone` and a `size`.

- Pick a name from morph, content, check, search, shield, alert, bars, bolt, globe, pin, lock and arrow.
- Choose one secondary `tone` per icon: ember, sun, peach, rose, lime, lagoon, haze, lilac or cobalt. Use `ink` for a neutral icon.
- Keep the grid dim at 14% opacity on both themes. The lit pixels carry the meaning.
- On Paper, the component deepens each hue so lit pixels hold 3:1 against the page.
- Size icons in steps of 8px from 24px to 72px. Lead a box cell with a 36px icon.
- Pair every icon with a visible label, and let the label carry the meaning.
- Draw new icons on the same 12 by 12 grid with a 2px gap, two pixels of padding and square pixels with `radius-px` rounding.
